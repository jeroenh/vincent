## Developer Certificate of Origin (DCO) — required 
All commits must include a DCO sign-off line. 
 
Use: 
git commit -s -m "Your message" 
 
This adds a Signed-off-by: line to the commit message. This is not the same as 
cryptographic commit signing.

before their first contribution is merged. 
 
## Contribution workflow 
1. Open a pull request (PR). 
2. Ensure all commits are signed off (git commit -s). 
3. If you are a first-time contributor, sign the CLA in CLA.md and provide it as requested. 
4. Address review feedback. 
5. Maintainer merges. 
 
## Security 
Do not open public issues for security vulnerabilities. See SECURITY.md for reporting guidance.
