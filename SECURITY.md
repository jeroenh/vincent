# Security Policy 
 
## Reporting a Vulnerability 
If you believe you have found a security vulnerability, please do not open a public GitHub issue. 
 
Instead, contact the maintainers privately with: 
- a description of the issue, 
- steps to reproduce, 
- affected versions/commits (if known), 
- any suggested remediation. 
 
## Coordinated Disclosure 
We will acknowledge receipt and work toward a fix and coordinated disclosure where appropriate.
